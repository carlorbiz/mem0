## Executive Summary

This document provides the **Handbook Integration Crosswalk**, a comprehensive mapping between the restructured 6-part ACRRM Practice Manager Handbook and the decision tree architecture. The crosswalk ensures that every section of the handbook is integrated into relevant decision nodes, and that every decision node draws from appropriate handbook content. This bidirectional mapping enables seamless navigation between the handbook (reference document) and the decision tree (interactive tool).

**Critical Design Principle:** The handbook and decision tree are complementary, not redundant. The handbook provides comprehensive reference material; the decision tree provides interactive, context-specific guidance. The crosswalk ensures users can move fluidly between both resources.

---

## 1. Crosswalk Structure

The crosswalk is organized in two directions:

### 1.1 Handbook → Decision Tree Mapping
**Purpose:** Shows which decision nodes are informed by each handbook section  
**Use Case:** Content developers can identify which decision nodes to update when handbook content changes

### 1.2 Decision Tree → Handbook Mapping
**Purpose:** Shows which handbook sections support each decision node  
**Use Case:** Practice Managers can access detailed reference material from decision nodes

**Part 1 provides foundational context** that informs all decision nodes but is not typically the primary source for specific decision-making. It establishes:

**Integration Strategy:**
- Use Part 1 content to populate "Decision Context" sections in decision nodes
- Reference Part 1 when explaining stakeholder roles in "Stakeholder Engagement" sections
- Draw on Part 1 for cultural safety considerations in relevant conflict detection nodes

## 10. Bidirectional Navigation Implementation

To enable seamless navigation between handbook and decision tree:

### 10.1 Handbook → Decision Tree Links

**Implementation:**
- Each handbook section should include a "Related Decision Nodes" callout box
- Example: In Part 3, Section "Mandatory Employment Compliance," include:
  > **Related Decision Nodes:** For interactive guidance on employment contract selection, see Decision Node I.1. For NTCER compliance checklist, see Decision Node I.2.

### 10.2 Decision Tree → Handbook Links

**Implementation:**
- Each decision node includes "Handbook Reference" section (already in template)
- Provide direct links to specific handbook sections, not just part numbers
- Example: In Decision Node I.1, include:
  > **Primary Handbook Reference:** Part 3: Employment & Financial Compliance, Section "Mandatory Employment Compliance: NTCER 2026.1 Principles" (pages X-Y)

## 11. Content Synchronization Protocol

To ensure handbook and decision tree remain synchronized:

### 11.1 When Handbook Content Changes

**Process:**
1. Identify which decision nodes are affected (use Handbook → Decision Tree Mapping)
2. Update affected decision nodes to reflect new handbook content
3. Verify cross-references are still accurate
4. Update "Last Updated" date in affected decision nodes

### 11.2 When Decision Tree Structure Changes

**Process:**
1. Identify which handbook sections are affected (use Decision Tree → Handbook Mapping)
2. Update "Related Decision Nodes" callout boxes in affected handbook sections
3. Verify bidirectional links are still accurate
4. Update crosswalk document to reflect new structure
